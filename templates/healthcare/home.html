ABOUT THE PROJECT

One platform for essential healthcare workflows.

CareSync is a web application built to demonstrate how healthcare information can be organized and managed through a structured backend and a responsive interface.

Django handles application logic and data management, while Django REST Framework provides API endpoints. Role-based permissions separate administrative operations from doctor access.
